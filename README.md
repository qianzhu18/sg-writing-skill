# sg-writing-skill

> 从新概念作文一等奖得主孙宇晨的文字训练出发，教你写动人的情话，也教你把一个故事写完整。

`sg-writing-skill` 是一个中文写作 Agent Skill。它把孙宇晨早年公开写作经历、公开文章中可观察的表达方法，以及社区对其文字的讨论，整理成一套可以直接使用的写作流程：

- 写出不油腻、不过度解释的动人情话
- 把一段经历写成有时间、人物、动作和转折的叙事故事
- 把同一件事拆成伴侣、公众人物、服务人员和助手等不同视角
- 用细节、数字和物件承载情绪，而不是堆砌形容词
- 把普通 AI 文案收紧成更像人在说话的中文
- 在故事性、文学感和事实边界之间保持分寸

本 Skill 学的是写作技法，不是冒充作者。它不复制原文、不代替孙宇晨本人发声，也不把虚构的恋爱细节或现实争议写成事实。

## 为什么是孙宇晨

孙宇晨（Justin Sun）不仅以创业者身份被公众熟知，也有一段明确的文学训练经历：2007 年，他获得第九届全国新概念作文大赛一等奖，并因此获得北京大学自主招生加分机会。澎湃新闻对他的采访记录了这段经历，也记录了他对《萌芽》、韩寒、王小波和李敖等文学影响的回忆。

他后来在《萌芽》发表《一道论证题》，用自己的求学经历、考试分数、选择和行动写成一篇面向同龄人的文章。文章的感染力不只来自“我有理想”这样的判断，而来自一连串可验证的过程：失败、重写、坚持、选择，以及最后的结果。

这正是本 Skill 想教你的部分：

> 不要先告诉读者你有多爱、多痛、多遗憾。先写你在几点几分做了什么，手里拿着什么，又把什么留下了。

## 这个 Skill 教你什么

### 1. 写动人的情话

动人的情话不一定是华丽的告白。它可以是一件小事、一件旧物、一个只有两个人知道的时间点，或者一句说完就停的话。

```text
不要只写：我真的很想你。

可以写：
我路过便利店，买了两盒你不喝的牛奶。
收银员问我要不要袋子。
我说不用。
```

写情话时，本 Skill 会帮助你：

- 把“我爱你”换成对方能看见的动作
- 找到一个能反复出现的物件，让关系有记忆点
- 用一个准确时间、金额、距离或数量让情绪落地
- 保留停顿和没说完的话，不把感动解释过度
- 根据关系阶段调整语气：初见、暧昧、热恋、争吵、告别各不相同

### 2. 写好一个叙事故事

故事不是把发生过的事按时间罗列一遍。一个能读下去的故事，至少需要一个现场、一个愿望、一个阻力，以及某种变化。

本 Skill 使用这条简洁骨架：

```text
一个具体现场
→ 人物正在做什么
→ 哪个细节出现偏差
→ 人物如何选择或被迫选择
→ 一个结果或未完成的动作
→ 留给读者的最后一句
```

它会提醒你：

- 开头先落地到时间、地点和动作，不先发表感想
- 让人物通过选择和反应暴露性格
- 重要场景慢写，过渡和决定快写
- 用少量数字建立真实重量，而不是让全文变成流水账
- 结尾留下结果、物件或动作，不用“这就是人生”替读者总结

### 3. 让文字更像人，而不是像模板

社区对孙宇晨文字的讨论有明显分歧：一部分读者认可其第一人称叙事、细节密度和“像小说一样往下读”的能力；另一部分读者则提醒，故事性和传播性很强，不等于事实已经被证实，也不等于所有修辞都值得照搬。

因此，本 Skill 保留有用的部分，主动过滤危险的部分：

| 保留 | 避免 |
|---|---|
| 场景、动作、物件、数字 | 无来源的“真实细节” |
| 第一人称的现场感 | 用第一人称伪装事实确定性 |
| 情绪留白和节奏变化 | 直接复制原文句式和数字组合 |
| 有冲突的故事推进 | 用隐私、争议或金钱刺激代替内容 |
| 克制的收束 | 把情话写成夸张的营销口号 |

### 4. 用多视角把一个故事写厚

同一件事换视角，不是简单替换人称，而是重新分配“谁看见了什么”。伴侣看到关系里的压力，酒店管理员看到清洁单和门卡，助手看到行程与取消记录，被提及的公众人物只能确认自己的记忆。信息边界不同，故事才会出现新的层次。

仓库中的[多视角叙事案例](references/multi-perspective-case-study.md)提供了一份完整练习：它根据用户提供的公开文本提取共同事件框架，再用四个角色位置做原创改写，并明确标注文学化虚构。涉及现实人物时，本 Skill 不冒充本人、不捏造私密事实，也不复现原文。

## 核心写法

| 技法 | 具体做法 | 自检问题 |
|---|---|---|
| 现场先行 | 先写时间、地点、动作或物件 | 读者能不能立刻看到现场？ |
| 情绪下沉 | 用行为、身体反应和物件代替解释 | 如果删掉情绪词，故事还成立吗？ |
| 数字锚点 | 每个短篇只选一至三个有用数字 | 这个数字改变了读者的理解吗？ |
| 事实并置 | 把两个有关系的事实放在一起 | 并置后是否不需要作者解释？ |
| 快慢相间 | 核心过程慢写，过渡决定快写 | 重要处是否比次要处更有篇幅？ |
| 留白收束 | 用动作结果或物件状态结束 | 结尾是在收住，还是在说教？ |

## 直接使用

安装：

```bash
npx skills add qianzhu18/sg-writing-skill --skill sg-writing-skill
```

查看是否能发现：

```bash
npx skills add qianzhu18/sg-writing-skill --list
```

安装后重新加载 Agent，然后可以这样说：

```text
用 SG 写作写一段给异地恋人的情话，不要出现“我爱你”，控制在 200 字以内。
```

```text
把这段经历写成一个完整的叙事故事：保留日期、人物和金额，用动作表现情绪，结尾不要讲道理。
```

```text
帮我写一个人在医院门口等消息的故事，要有清晰的冲突、一个重复出现的物件和克制的结尾。
```

```text
把同一件事分别从伴侣、酒店管理员和助手视角写三版；事件保持一致，但每个人只写自己能知道的部分。
```

```text
请诊断这段文字为什么像 AI，从情话、场景、句子节奏、数字和结尾五方面给建议，先不要重写。
```

也支持：`孙宇晨文风`、`SYC 风格`、`克制散文`、`冰山叙事`、`数字锚点散文`、`去掉 AI 味`。

## 适用范围

适合：

- 情话、情书和关系叙事
- 第一人称回忆、个人故事和人物小传
- 中文散文、公众号文章和短篇故事
- 把抽象情绪改写成动作、物件与场景
- 对已有文本做节奏、细节、留白和结构优化

不适合单独承担：

- 新闻报道、法律意见、医疗建议和事实核查
- 技术文档、学术论文和数据报告
- 需要强转化目标的营销文案
- 未经核实的真实人物故事或私密关系叙述

## English

`sg-writing-skill` is a Chinese writing Agent Skill inspired by the publicly documented writing background of Sun Yuchen, a first-prize winner of the ninth New Concept Writing Competition. It teaches restrained love lines and complete narrative stories through scene-first openings, purposeful details, numeric anchors, physical actions, contrast, pacing, and quiet endings.

It is a technique-oriented writing tool, not an impersonation or text-reproduction tool. It supports generation, rewriting, tightening, and diagnosis while preserving user-supplied facts and separating fictional details from real-world claims.

Install:

```bash
npx skills add qianzhu18/sg-writing-skill --skill sg-writing-skill
```
