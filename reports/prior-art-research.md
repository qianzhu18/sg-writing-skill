# Design notes: sg-writing-skill

## Core technique profile

The Skill focuses on a concrete combination of short-sentence rhythm, purposeful numeric anchors, iceberg narrative, juxtaposed facts, and restrained closing lines. Each technique is written as an observable choice so it can be applied without imitating a person or copying a source passage.

## Deliberate choices

- Keep familiar trigger phrases for SG, SYC, restrained prose, iceberg narrative, and numeric anchors.
- Separate writing generation from rewriting, tightening, and diagnosis.
- Treat numeric density as a guideline, not a quota.
- Protect facts supplied by the user and label creative invention as fiction.
- Use contextual anti-pattern checks instead of deleting every emotional word.
- Treat named-author requests as high-level technique abstraction and maintain an originality boundary.

## Known limitation

The repository contains static trigger cases and human-readable eval prompts, but no automated model benchmark. Qualitative review with the target Agent is still needed to assess voice consistency, factual preservation, and usefulness across different prompts.
